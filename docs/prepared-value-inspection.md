# Inspect complete prepared preview values

Data preparation now offers **Inspect all prepared values** after previewing a step or the applied history. The existing first25 final differences remain. Inspection captures the complete bounded prepared dataset through the existing read-only local-row engine, then offers a stored-field selector,50-row pages and direct row jump. Every declared/stored key is available when within inspection limits. Select a value for the full reversible JSON string; CR,LF andCRLF remain distinct. Missing own properties and empty strings are distinct. Source row positions are positions,not respondent identities.

Inspection never applies a proposed step,checks the review attestation,adds/saves a study,changes recipes or rewrites original/source/history. Captured snapshots are immutable; refreshing explicitly captures again. Replacement preview ownership aborts an earlier capture and hides an earlier snapshot. No alternate or partial study is substituted. Cancellation,timeout and bounded-size refusal leave the recipe and preview available. The synchronous single-flight ref refuses same-event duplicate activations. Closing/replacing owned content returns focus conditionally; deliberate outside focus or blur is not stolen. Unmount returns owned focus to the existing preparation modal. Existing keyboard/modal guards remain in force.

Inspection intentionally uses the existing smaller local-row limits:50000rows,200distinctkeys,500000storedcells,8Misourcecharacters,65536characters/value. A valid larger preparation can refuse inspection without losing its preview. Chunked capture yields; final verification and rendering are synchronous,not native responsiveness or total-memory guarantees. This view makes no fetch/export/download. Raw respondent values are sensitive,unencrypted and not anonymized.
