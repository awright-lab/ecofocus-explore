# Explicit local SPSS background import

Home's **Import local CSV or SPSS** opens the existing local import review. CSV remains the default. Select SPSS (.sav), choose a supported file, inspect complete row/field counts and parser notes, then explicitly add it. Format changes are disabled during parsing and preview. Discard a preview to choose another format or file. This route does not upload the file or fall back to a service; configured Import data routes are unchanged.

The existing SAV parser runs in a module worker through the acknowledged CSV transport. A separate SAV entry point fixes expected format on both sides. Main-thread validation checks local provenance, source filename, dimensions, metadata, preview indexes, packet ordering, complete string cells and final row counts. No study is added before completion and explicit review. Existing duplicate review, pending-save recovery and original-study retention apply. File input reset permits same-file retry after failure/cancellation.

Limits: source file 16 MiB; one million rows; 5,000 fields; two million cells; 128 Ki characters per value; 32,768 physical SAV slots; expanded row JSON 16 Mi characters; metadata header 2 Mi characters; packets 256 Ki characters / 500 rows. Intermediate parser allocations occur before expanded-data validation, so these are not total memory guarantees. Receiving, validation, duplicate checks and saving still include synchronous work. Sixty-second inactivity deadline depends on event-loop scheduling. Cancellation detaches acceptance and requests termination; if termination itself throws, acceptance is still revoked but stopped computation cannot be promised.

Synthetic verification includes compressed/uncompressed SAV, missing markers, finite numeric extremes, malformed/truncated cases, packet integrity and acknowledgements, cancellation/lifecycle errors, format isolation, and real Node worker execution without DOMParser or fetch. Actual App tests import 1,000 rows, simulate quota refusal, retry the complete pending study, create a two-category count analysis and save/reopen in the same process, preserving the original study and published report/history. This is not a browser restart, native worker/CSP/file-picker test, total-memory or latency measurement, or SPSS interoperability certification. Native accessibility/touch, browser matrix, live backends, Office and production build remain unverified. The blocked build was not retried.

Only supported SAV parsing is exposed; parser semantics/metadata limitations are unchanged. XLSX background import is not added because its current parser depends on DOMParser. Browser workspace data remains unencrypted and is not anonymized or synchronized across devices. Keep source files and backups. No historical caches are rewritten. Goal 15 remains partial; no publication, deployment or additional goal closure is implied.
