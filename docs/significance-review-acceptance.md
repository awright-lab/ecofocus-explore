## Supported workflow

Use a complete original local-file study with 1–50,000 rows and at most 20 MiB of selected source values/metadata. Choose separate unique respondent-ID, single-valued categorical group and categorical outcome fields; numeric-coded dimensions must be explicitly modeled as categories. Select one reference and 1–20 distinct comparison groups, explicit event codes and optional outcome exclusions. All other eligible nonblank outcome codes count as non-events. Missing outcomes, excluded codes, missing groups, unselected groups and unknown audience membership have separate counts. Each group has its own valid respondent denominator.

Optional saved audiences use their existing source-bound rules. The user must describe the research/sampling context and explicitly acknowledge independently sampled, unweighted respondents and the chosen comparison family. Weighted, paired, repeated, clustered and unknown designs are blocked. Unique IDs are checked throughout the entire source, including excluded rows; this does not establish actual sampling independence or representativeness.

Review acknowledgement binds the complete plan to exact selected source values, metadata, import identity and audience definitions/inputs. Changes remove results and revoke acknowledgement; changed field identities require explicit resetting. Counting uses an immutable initial projection, yields with progress/cancellation, then rechecks the current source before accepting results. No source or report content is changed. Closing/leaving the page warns about the temporary plan; explicit discard clears it. This is not persisted analysis or crash recovery.

## Methods and interpretation

- Each eligible comparison uses a **two-sided, probability-ordered Fisher exact test** on integer event/non-event counts. Hypergeometric probabilities are evaluated with stable log recurrences and compensated summation; exact integer ratios/prime products resolve ties and near-ties in probability ordering. This follows the [Fisher definition documented by SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.fisher_exact.html), with numerical evaluation rather than a normal/chi-square approximation.
- **Holm step-down Bonferroni** covers the entire selected family, including the common reference. Empty/no-variation comparisons are uninterpreted, remain visible and conservatively retain p=1 positions in that family. No sample or p-value is fabricated for an empty group. See the [statsmodels method documentation](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html).
- Effect size is the unrounded event-rate difference from the reference, in percentage points. Raw/adjusted p-values, counts, valid bases, alpha, exact 2 × 2 tables, missing/excluded outcomes, small-base/sparse-cell cautions and calculation values before display rounding are available.
- Very small p-values remain finite logs and display `<1e-300`, never a rounded zero. Numerically borderline alpha values are explicitly flagged. Rates/differences display one decimal and p-values four significant digits; decisions use unrounded calculations.
- A p-value does not establish practical importance, causation, the probability a hypothesis is true or equivalence when above alpha. Decisions need effect magnitude, sampling context and full reporting, consistent with [ASA interpretation guidance](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf). One selected-family adjustment does not control all error introduced by repeated exploration or choosing families after seeing results. Different missingness/exclusions can change the population being compared.

Existing canvas/cached-result inference safeguards remain unchanged. This tool computes from complete raw local rows and does not certify older cached test claims.

There is no new transactional storage, cloud publishing or authenticated collaboration.
