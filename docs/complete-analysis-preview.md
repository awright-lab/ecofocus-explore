# Inspect the complete analysis preview

Create analysis now offers **Inspect complete preview** after a result is available. It opens a full-width view inside the existing modal, with answer/column search, paged access to every calculated cell, original labels and IDs, numeric precision, valid bases, notes and warnings. Return to analysis setup keeps the chosen question, groups, filter and calculation.

The inspector is temporary. It does not add, save, export, recalculate or replace a report analysis. Creation is disabled during inspection. After returning, Create still runs the existing fresh calculation from the selected source; the temporary view object is never inserted into a report. Small-study immediate previews and large-study optional background previews keep their existing calculation and validation paths. Illustrative sample results remain labelled as such.

Inspection is bound to the exact current result. A replacement result or revoked background preview closes it before stale cells can be painted beside the new setup. For local immediate previews below5,000rows, an exact ephemeral identity tracks selected raw values, field metadata, import identity and source dimensions on every render, including edits that retain the same object references. It uses the engine's exact-first/case-insensitive source-key rules. Changed selected inputs recalculate and revoke inspection; restoring old inputs does not automatically reopen it. Unselected columns are excluded. This checks rendered input currentness, not cross-tab/crash durability. Controls stay within one modal rather than opening nested dialogs. Focus moves into inspection, returns to its trigger when appropriate, and respects newer outside focus or deliberate blur. Hidden setup controls leave the visible tab cycle while inspection is open.

The existing saved-result dialog and this preview share the same table browser. Its original recorded-mode helpers, state and markup are reconstructable from the extracted component; calculation, analysis creation, saved-table behavior and numerical formatting remain unchanged. The filter object is memoized so a view-only render does not unnecessarily recreate a filtered immediate preview; exact selected-input identity prevents this memoization from hiding in-place source edits. Small-preview identity is bounded before JSON allocation (2MiB UTF-8 metadata,20,971,520JSON characters of selected values). If identity cannot be established, inspection is unavailable with an error, while Create can still attempt the existing fresh original-source calculation. Sample-query dependencies apply only in sample mode, so unrelated sample prop changes cannot close an imported-study inspection.

Synthetic verification includes350cell result browsing, final-page values and bases checked against respondent rows, searches/reset, filtered inspection, fresh original-source creation, source changes, background preview invalidation, sample labelling, Escape/Tab and focus ownership. An actual App workflow uses1000rows and30fields, preserves an existing selected analysis and published snapshot through inspection, creates a separate350cell analysis, validates every value/base against an independent row-count oracle and cold reopens the saved report/source/history. No live request is made.

Native browser layout, assistive technology, touch/fullscreen, Office/download and live Snowflake/backend acceptance remain unverified. This is progress in pre-create result review and navigation, not completion of weighted change previews, remote discovery or the broader forty goals. Publication, deployment and recovery/restore gates remain unchanged.

Selected-input identity also records the authoritative row origin (full `rows` versus complete `previewRows`) and the engine-normalized source reference. Switching equal-valued rows to a preview-only source refreshes the engine warning and revokes inspection. In-place source-reference edits refresh query/source provenance even when the numerical cells do not change. Normalization-equivalent raw overrides and unused preview-row edits do not invalidate an authoritative full-row preview.
