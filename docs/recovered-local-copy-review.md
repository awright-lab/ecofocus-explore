# Recovered local file copy choices

This closes the late Home-import route gap identified in independent review of 8b6a850. Deferred recovery already required an explicit Add recovered studies action; it was never an automatic save. That action now offers reuse versus separate studies for complete, unprepared browser-local Excel and SPSS copies when a match is found or cannot be verified. CSV recovery and managed/partial/prepared sources keep their existing checks.

The planner first applies existing identity, reserved-reference and metadata validation. It compares at most 20 eligible queued studies with the existing bounded exact comparator. Unchecked copies are retained separately. It never changes existing report references, guesses study waves, or drops nonredundant previews. An explicit reuse selection is rechecked against current queue signatures, target identity/version and complete content; changed choices require a fresh read-only review. Only a confirmed save retaining the original data permits acknowledgement of the captured queue entries. Failed or uncertain saves keep the recovery copies available. This is in-memory recovery, not crash durability.

Builder imports now reject overlapping reads within the mounted editor, defer results after report replacement or a conflicting pending-save context, and capture the latest command-time draft before adding a new study. Duplicate or unchecked local Excel/SPSS results go to the recovery choices rather than silently creating another copy. Home updates its command-time workspace reference after a completed import. No global cross-tab mutex or transactional writer is claimed.

Tests use actual synthetic XLSX and SAV parsing, the application shell, real workspace writer and same-process reopen, plus bounded planner, queue acknowledgement, failed-save, mutation and conditional-focus regressions. Browser-native file parsing, downloads, quota policy, process crashes, simultaneous tabs and broad accessibility remain unverified. Goal 4 remains partial; no deletion, migration, production service, permission or credential changes are included.
