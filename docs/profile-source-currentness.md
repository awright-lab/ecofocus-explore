# Field profile source verification

Small numeric and categorical inspections recalculate on render, including same-reference row and selected metadata changes. Previously their object-reference memo could retain old means or category labels. Synthetic probes reproduced both stale small-summary and stale-worker acceptance before this correction.

Background numeric/category profiles now bind source identity, import, coverage, storage mode, selected metadata and registered-field context before preparation. Each preparation chunk checks that context. On completion, selected values are compared with the captured column in bounded chunks of at most 5,000 values, checking context between chunks. For larger columns, a final uninterrupted read-only pass catches edits to earlier chunks made during a yield. Changed values or metadata refuse the profile; cancellation and the existing single 30-second watchdog remain active through verification. Unrelated column changes do not invalidate a selected-column summary. No dataset or workspace writes occur.

Completed background summaries are explicitly labelled snapshots. A Refresh action reruns inspection and immediately hides the earlier result using an attempt-bound job record. It retains conditional focus recovery and never treats old results as the pending attempt. A completed profile is not a continuously monitored source: later in-place edits require explicit Refresh; normal replacement dataset/field props still start new jobs.

This checks point-in-time selected values and metadata, not source authenticity or a transactional snapshot. Changes that are restored entirely between checks cannot be detected; JavaScript getters/proxies/serialization hooks, hostile worker output, cross-tab source changes without object updates and server/cloud revision semantics are outside this guarantee. The final pass is O(selected rows) on the main thread and adds no second column copy; worst-case latency is unverified. Timers depend on the event loop and do not interrupt this synchronous pass. Native browser Worker/CSP/performance/accessibility and production-build gates remain open. Goal 15 remains partial.
