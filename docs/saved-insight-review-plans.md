# Saved report insight definitions — candidate

Extends the existing reviewed comparison feed toward original goal 26. Explicitly added review plans now travel with the report through normal browser saves, recovery and Undo/Redo. Reopening starts with those definitions, never a cached calculated feed. The rendered definition signature is revalidated on every render, including same-reference in-place changes, so an accepted feed cannot remain visible under edited definitions. Running recounts the original current sources and applies the existing full selected-family Holm adjustment. The statistical calculation and sampling assumptions have not changed.

## Boundaries and preservation

Only definitions, selected-field metadata bindings and source digests are saved: up to five complete families, 20 total comparisons and the existing 2 MiB metadata bound. Field metadata can contain profiles/sample values, so this is not an anonymization feature. No additional respondent row arrays, comparison counts or calculated probabilities are stored in this property. Definitions remain bound to their recorded report and source version; duplicated/new-wave reports do not silently inherit approval under a new report ID. Stale source digests require explicit re-review, not automatic rewriting. The local comparison source gate also refuses conflicting recorded kind, provider or dataset identity rather than interpreting a live/managed reference as local.

Malformed/future/wrong-report collections stay in the document as quarantined metadata. They cannot produce findings or be added over silently. Clearing them is explicit and undoable. Source dependency inspection retains readable source IDs even for quarantined plans; unreadable libraries block study removal and new snapshots instead of permitting unknown dependencies to disappear. Valid definitions retain source studies in snapshots even when no visible tile references that study.

A source review hashing in the background cannot resurrect a collection after it is cleared or changed, navigate into another report, write after unmount, or report successful admission when the command is rejected. Same reviewed definitions do not add duplicate history entries. A failed browser save keeps the full edited report and its plans in the existing recovery buffer. The UI distinguishes admission from the normal save acknowledgement; it does not claim calculations or source rows were saved by running the feed.

The existing temporary hook remains available to its nonpersistent consumers/tests; the actual builder uses the report-backed hook. Calculations in the comparison editor and feed remain temporary; display cutoffs, feed alpha and research-priority selections are panel-local and reset on close. Save/Undo operations on plan definitions affect the report, as the updated labels explain. Clearing a focused collection returns focus to a stable control, without overriding a newer deliberate focus choice.

## Verification and limits

Tests cover exact definition serialization, fresh recount after reopen, stale-source refusal, source dependency/snapshot retention, malformed metadata quarantine and explicit clear/Undo, late admission ownership/clear/unmount, command refusal, unchanged rows, and clear-control focus. The actual App journey adds two families, verifies exact persisted definitions, simulates quota failure and Retry, removes/clears/undoes, remounts and recounts the complete three-comparison family. Its preservation baseline is taken after the existing codec has compacted redundant previews; complete raw rows and fields are verified independently. Programmatic reviews against unnormalized pre-storage sources are not silently rebound when canonical import metadata changes.

This does not complete original goal 26: automatic report-wide/chart or cross-wave discovery, cloud synchronization, native/browser/AT acceptance and broader intelligence workflows remain. Existing statistical support is complete original local unweighted independent-respondent event-rate review only. Plans are descriptive records of human assumptions, not authentication, survey-design validation or proof of representativeness. Production build remains unattempted after the prior EPERM; no denied socket, chooser, Office, publication or deployment action was retried.
