# Synthetic cross-feature report journey

The composition regression combines actual local CSV import, saved audiences, summary counts, a two-column regional heatmap, a reusable paired-cell formula, semantic report colors with an explicit answer override, two evidence links, immutable local snapshot history, the real workspace save session/codec, source refresh and real XLSX/SVG construction.

It runs at 1,000 and 10,000 respondents with thirty fields, each with and without an injected storage failure. The imported rows and source headers are compared with the independently generated input matrix. A separate raw-row counter establishes source/group values and bases. Core respondents have a Yes/No index of 25; Other respondents have an index of 400. The original dataset is never changed: only the explicitly selected audience and resulting report analyses change.

Switching audiences regenerates frequency-based answer IDs. The Yes override must remain attached to its original raw source category, while old text evidence and the calculated output must become stale and block exports. Saving that stale state preserves the recorded result rather than fabricating a refresh. When the write fails, exact older stored bytes remain, the complete candidate remains pending, and Retry saves it. A fresh save-session instance reads the saved workspace. Explicit formula refresh and text re-review then restore export eligibility. Original study bytes and published local snapshot history remain exact through the final reopen.

Real workbook blobs are parsed as ZIP/XML and checked for summary counts, common response bases and formula values. The optional private test artifact directory retains those XLSX files, independent raw-row oracles and reconstructed SVGs for every page before and after refresh. These are synthetic local files, not an online publication or OS download. Standard-library ZIP/XML checks can independently verify counts, regional bases, evidence context and generated geometry.

This is core/model integration coverage. It does not render or automate the App UI, instantiate a real browser Worker, use a file chooser, navigate a separate browser process, download a file through the operating system, render pixels or open Office. Reopen uses a new session in the same test process. Storage failure is injected; no actual browser quota, multitab/crash guarantee, live service, production build or full original-goal closure is claimed. Goal 5 remains partial.

The regression adds no production behavior. It is isolated from the main working tree and obsolete staged index, preserving all accepted candidate snapshots and backups. No canceled staging, denied build, browser/socket/Office action, publication, merge or deployment is retried or enabled.
