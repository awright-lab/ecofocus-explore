# Preview pending seeded query settings

The selected analysis Apply and save controls now offer Preview pending query for ordinary non-imported saved queries. Existing query controls can record a pending filter, metric, weight, breakout or question while retaining the last executed result. This explicit preview runs a separate query and displays both results, bases, recorded settings and the complete searchable result review without replacing the result or saving the workspace. Refresh analysis still executes a fresh query before applying it. There is no apply-preview shortcut.

Preview and refresh share the existing non-imported source route and saved variable-set row resolver. Explicit illustrative sample identities remain local and keep their existing unsupported-filter/authored limitations. Untagged queries use the same configured analytics endpoint as refresh. The server provider and data can change between requests; no pinned revision or live correctness is implied. Connected live-source identities/references refuse this preview and require their dedicated live-query workflow. Existing imported and calculated-result preview routes remain separate. All derived extracts, summaries, differences and averages refuse this generic preview; their dedicated recreation/metric controls preserve their calculation meaning.

The response must bind to the requested query, metric/format, study/question/breakout and consistent table/series cells and bases before it is displayed. Ordinary unweighted respondent bases and counts must be safe integers; weighted fractional totals remain supported as totals. This validates transport and displayed-cell consistency, not the correctness of server calculations, survey variance, statistical claims or source authentication. Weighted totals stay labeled as weighted totals; weighted inference is not invented. Arithmetic differences remain subject to the existing conservative local-unweighted comparison gate.

Immutable bounded snapshots (existing 16 MiB recovery-data limit) cover current result, pending query, source and relevant saved-row definition. Serialization hooks and unsupported raw metadata refuse. Changed query/result/source/definition/editor context, starting a refresh, cancellation or unmount invalidates the preview. An AbortSignal reaches the server request where supported; server computation may continue, but a late response cannot be displayed or applied. Focus stays in stable controls when transient cancel/review controls disappear, without taking deliberately moved focus. The trigger uses aria-disabled with guarded activation to remain keyboard reachable.

Verification uses actual mock-provider calculations behind mocked transport, real App/session persistence and existing ownership tests. Live Snowflake/provider correctness, real network cancellation, browser timing, native assistive technology and production build acceptance remain unverified. The prior build EPERM is preserved without retry. Goal 13 remains partial pending broader original-scope and native/live acceptance; no production service, credentials, permissions, deployment or billing changes are made.
