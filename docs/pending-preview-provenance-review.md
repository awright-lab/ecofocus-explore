# Pending-preview provenance and ownership correction

Independent review identified explicit imported references that could reach the generic endpoint through a question-shaped tile, and accessor values read while constructing a snapshot before original-object validation. New checks validate the complete original tile and saved-row library before property reads, spread or filtering. The existing 16 MiB aggregate plain-data budget now also covers that original input graph; unsupported accessors, hidden metadata and serialization hooks refuse without execution. This guarantee applies at the preview-snapshot and direct executor entry points; existing authoring selectors are not a general sandbox for arbitrary JavaScript objects. This is a normal plain-object data contract, not protection against arbitrary malicious JavaScript proxies or modified runtime intrinsics.

The shared ordinary-query route validates query/source data before inspecting it. Pending query, recorded query, cached metadata and tile source references are checked explicitly. Imported-file/workspace-database references use their dedicated imported context; connected references use the live-query workflow. Unsupported identities/references refuse. Ordinary untagged server queries and correctly tagged illustrative sample queries keep their existing routes. Generic refresh also fails closed for these unsupported references, rather than guessing a seeded source.

A synchronous request owner prevents two activations in one React event batch from starting two requests. Canceled or invalidated owners no longer block a replacement request even if their transport ignores abort; an old completion cannot release a newer owner. The current request still uses the existing source/editor snapshot checks.

Expanded-review dialogs now capture focus ownership before removal. Their existing modal cleanup restores inert and scroll state first, then a disappeared parent preview can conditionally restore focus to its connected controls. Deliberately moved or blurred focus is preserved. Normal dialog close still returns to its internal review trigger. Native browser/inert/assistive-technology acceptance remains open.

Regression tests cover all explicit provenance roles, original accessors, direct execution, two activations before rerender, canceled/invalidated replacement requests, late completion, expanded-modal invalidation and real App refusal/preservation/reopen. They use synthetic data and mocked transport. No server arithmetic/weighting, real crash or universal cross-route guarantee is claimed. Goal 13 stays partial. The existing build EPERM and native gates remain preserved without retry; no publication, merge, deployment or security settings changes.
