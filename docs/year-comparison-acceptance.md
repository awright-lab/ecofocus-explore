# Year comparison review candidate — original goal 17

Goal: map questions, answer codes, populations and weighting changes across study waves, and flag breaks in comparability.

This candidate adds **Find a tool → Analyze → Check a comparison across years**. It is a temporary descriptive review of two different, complete, original local-file imports, with 1–50,000 rows each. It does not write studies, reports, snapshots or saved analyses. Closing it clears its plan and results. Independent acceptance of the original goal remains pending.

## Implemented workflow

- Choose chronological years, explicit original imports, separate question and unique respondent-ID fields, and optional saved audiences for each wave. Search field wording, labels and source columns, including fields beyond the first 200 visible options.
- Describe each target population and declare whether an unweighted comparison is appropriate. Explicitly record question/answer-universe, population, weighting and sampling/collection equivalence, changes or unknown context, with a methodology/source note. These are human declarations, not automatic certification.
- Map each common meaning to one or more exact raw codes in both years. Many-to-one recodes count each respondent once. Reviewable exact-code suggestions never assume that identical codes have identical meanings. Missing answers remain missing; other observed audience answers require a mapping or deliberate exclusion. Declared zero-frequency options can map to zero; absent undocumented options are not invented.
- Inspect each wave's source rows, audience coverage, unknown membership, missing answers, explicit exclusions, mapped respondent base, counts and unweighted response shares. Each wave has its own denominator.
- Percentage-point differences use unrounded shares and are enabled only when all four declarations are equivalent, both weighting contexts explicitly support unweighted calculation and both bases are nonzero. Changed/unknown context withholds differences and explains the break. Weighted sources remain explicitly raw unweighted descriptions, with no weighted comparison. Small bases and excluded responses are flagged.
- Study/import identities, selected question and ID metadata, audience definitions and relevant field metadata, exact selected raw values and membership are rechecked before accepting a result and when displaying it. Missing/replaced/ambiguous sources do not silently fall back. IDs must be nonblank and unique throughout the entire study, including rows outside the audience.
- Counting yields every 500 rows, reports progress and supports cancellation. Inputs invalidate results and require review again. Population/audience changes reset the population declaration; weighting changes reset its declaration; question/study changes clear mappings and declarations.
- The dialog traps focus, makes its background inert, dismisses on Escape and isolates canvas shortcuts. The narrow layout uses one-column source/mapping controls and a separately scrollable result table.

## Deliberate limits and remaining acceptance

Independent review must assess the actual calculation and UI before this is counted as a completed original goal. Human-reviewed equivalence is not instrument validation, measurement invariance, verified target-population truth or proof of a common sampling frame. Respondent IDs are checked within each wave; matching IDs across waves do not establish a paired design.

Independent follow-up identified stale population attestation when an external edit changes a selected saved audience under the same ID. The correction binds the checkbox to its population context (audience definitions, import identity and referenced field metadata), aborts pending work, removes results and resets population equivalence to unknown on a context change. A second guard checks the binding at execution. Two real-component regressions reproduce a −50 to +50 point change and metadata reuse: old review no longer permits execution; reconfirming without redeclaring equivalence withholds changes, and only an explicit new equivalence review restores them. Focused verification now totals 40 model plus 13 component tests. Independent acceptance remains pending.

No weighted estimates, survey variance, significance tests, confidence intervals, automatic weight harmonization, paired inference, live Snowflake/remote analysis, prepared-copy analysis, longitudinal panel linkage, persisted mappings or export integration are claimed. Unsupported sources are explained rather than silently substituted. Native cancellation timing is covered by deterministic component/model tests, not claimed from the short browser fixture. No native Office rendering, OS download or production deployment was attempted for this batch.
