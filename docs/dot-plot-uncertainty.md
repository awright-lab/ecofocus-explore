# Individual rate intervals on dot plots

For a separate-series dot plot of a newly calculated local categorical percentage, Format offers **Show individual 95% Wilson intervals**. Enabling it is an explicit declaration by the report author that respondents follow an independent, unweighted binomial model. The application cannot establish sampling independence, representativeness or population coverage from the dataset alone.

Intervals use the exact recorded integer event count and valid denominator, never reconstructed rounded percentages. The existing Wilson implementation is validated for bases up to 50,000. Individual intervals stay at 95% regardless of the query/test confidence setting. They are not intervals for differences or simultaneous coverage; overlap does not test significance. A missing/zero valid base has no interval, whereas observed zero or all events retains uncertainty. Source exclusions, missing responses, nonresponse bias, clusters and survey weights are not accounted for by these intervals.

The choice is bound to the recorded query, source/import identity, row/column identities, values, bases and exact count pairs. A changed calculation requires turning intervals off and explicitly reviewing the declaration again. Display aliases, palette and layout can change without changing observations. Malformed or stale declarations refuse the drawing/export, retaining the original source and settings; they never silently draw ordinary dots in place of requested intervals. Historical charts remain unchanged and opt out by default. Unsupported weighted, remote, derived, authored, rounded-only, mean/count and paired-layout cases refuse this feature. No old result is silently recalculated or migrated.

The shared SVG renderer supplies all valid intervals and endpoint caps on one 0–100% scale to the canvas, thumbnail and PDF/PowerPoint visual paths. Numeric labels and per-cell titles include interval bounds; titles also retain exact events/valid bases. A keyboard-reachable HTML disclosure exposes every interval and its events/base outside the SVG accessibility tree; small valid bases carry a caution. Explicit fit errors protect dense/large-type fixed exports, while the canvas can scroll a complete drawing. PDF/PowerPoint include the declared assumptions in their analytical context. Dot plots remain image-based PowerPoint underlays rather than native editable charts. Excel continues to export the original analytical values, bases and context; it does not add interval columns or a survey-inference certification.

Regressions cover production engine counts, independent numerical references, shared-scale SVG geometry, rare/zero/all/empty outcomes, the 50,000-row bound, invalid/stale contexts, explicit opt-in/removal, focus ownership, shared export rendering and actual App save/retry/Undo/Redo/remount with exact source/history preservation. Artifacts use synthetic data and production export builders. Native browser, screen-reader, touch, actual quota, Office rendering and OS downloads remain unverified; no blocked operation is retried. Original goal 32 remains partial pending the remaining chart, weighted-design and native acceptance work.
