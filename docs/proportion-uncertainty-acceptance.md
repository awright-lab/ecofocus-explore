# Individual event-rate uncertainty

The existing reviewed group-comparison dialog now shows an uncertainty plot for every selected group, including its reference. A dot marks the observed event proportion and a line marks the two-sided individual 95% Wilson score interval without continuity correction. All plots share a 0–100% scale. Original events, valid respondent base, missing outcomes and explicit exclusions are printed beside the interval; no values need to be inferred from geometry. Raw category codes remain visible even with duplicate labels. An empty valid base has no invented rate, point or interval. Observed zero and 100% retain nonzero uncertainty. Bases below thirty have an explicit heuristic caution, not a claim that larger bases establish validity.

The interval uses the binomial score method documented by [NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm), with standard-normal 0.975 quantile `1.959963984540054`. Wilson coverage is approximate and varies with base and probability. It is not an exact binomial interval, a Fisher-test inversion, a difference interval or a simultaneous family interval. The display stays at 95% when the comparison test alpha changes; interval overlap is not used to decide significance. Existing Fisher tests, full-family Holm adjustment, effects, ranking and original counts are unchanged.

Percentage labels retain up to four decimal places, with at least one. This prevents a zero-event interval at the maximum base reading as an apparently certain0.0%–0.0%: its upper endpoint is0.0077%. Geometry uses unrounded coordinates. Very narrow intervals may still occupy less than a screen pixel at a fixed scale; the printed bounds remain available.

The feature is restricted to the existing explicitly reviewed independent, unweighted, original complete local-file workflow (1–50,000 source rows). It does not infer an unweighted denominator from a percentage or weighted total. Existing full-family count/base consistency checks run before rendering, and stale source contexts or incompatible design bindings have no interval geometry. The user's sampling declaration cannot be verified from rows. Nonresponse or missing-data bias, clustering, weights, finite-population corrections, paired/repeated observations, multiple-response dependence and representative/causal claims are not addressed.

Intervals remain a temporary review visualization. They are not persisted into report tiles or added to export formats, report-feed inference, cloud workspaces or live Snowflake execution. No workspace schema/writer, source data, saved report or dependency changes are included. The report-feed review corrections are tracked separately.

Verification includes 142 independent 85-digit Decimal score-equation bisection references (270 iterations per endpoint), zero/all-event and single-respondent cases, the 50,000-base boundary, all counts through base100 for bounds/complement behavior, malformed/weighted/stale input refusal, actual SVG point/endpoint coordinates, missing/excluded bases, literal raw codes and text labels. A real App workflow over a synthetic1,000×30study runs and reruns at test alpha0.05/0.1, checks identical 95% plots, closes and cold reopens the exact saved report/source. No canvas/editor/analytics/writer mocks or network calls are used. The test environment uses jsdom, not a native browser.

Original goal32 remains partial: this adds validated individual group-rate interval geometry in one reviewed workflow. General report-chart uncertainty, weighted survey methods, exported intervals, native browser/assistive/touch/visual acceptance and broader statistical coverage remain open. Nothing is published, merged or deployed by this candidate. The inherited TLS setting is unchanged; its warning is not a successful TLS check.
