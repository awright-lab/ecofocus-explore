# Report-wide export attention overview

Export review now offers a direct overview of all pages flagged by the existing synchronous report checks. It shows the complete affected-page and check totals, each page's original report ordinal/title, and counts grouped by existing check type. Selecting a page card updates the existing page preview and detailed findings without closing the dialog, starting an export or editing the report. The existing full page dropdown remains available, including pages with no findings. The active card is identified with aria-pressed; each card has a distinct ordinal and an associated check description.

This is navigation through the existing checks, not a severity ranking or export approval. Optional image decoding and Excel worksheet reviews remain separate, and their findings are not included in these counts. No new rendering, analytical or export correctness claims are made. A zero-finding overview explicitly retains the need to inspect the generated file.

If a focused card disappears on a rerender, focus moves to the persistent overview heading only if the removed card still owned focus and focus has fallen to the document body. Deliberate outside focus or blur is preserved. No focus is moved merely by selecting a page. An obsolete page ID refuses navigation instead of selecting a stale target.

Regression checks cover complete counts, duplicate page titles with distinct ordinals, grouped check descriptions, current selection, exact page navigation, stale-target refusal, owned/outside/blur focus, empty results, and an actual App workflow with a 1,000-row synthetic study. App checks retain exact saved workspace/draft/source/published snapshot data and verify same-process reopen; they are not crash or native-browser acceptance. Native screen-reader, keyboard, touch, scrolling, visuals, Office and downloads remain unverified. Original goal 36 remains partial. The candidate is isolated; checkout, obsolete index and prior backups remain unchanged. Nothing is staged, published, merged or deployed.
