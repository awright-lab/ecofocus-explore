# Local imported-study copy review

The exact bounded local-copy comparison now accepts complete, unprepared CSV, XLSX and SAV studies. A match requires the same format, file name, title, complete respondent strings and order, field metadata, notes and other metadata. Generated study IDs/import timestamps, ordinary generated source/status fields and derived preview/storage notes are treated as before. Different formats, analyst labels, altered raw values, changed row/key order, unknown source metadata and partial/remote/prepared studies are not silently merged. Budget exhaustion is unverified, not proof of no match.

Import data now pauses a complete browser-local Excel or SPSS import when the check finds a match or cannot verify it. Show existing study rechecks the current source and does not save. Import as a separate study explicitly keeps both records; the existing ID collision and pending-save protections remain. Failed saves retain the additive candidate in the normal save session for Retry. Saved data follows the existing storage note and 25-row preview compaction while retaining complete local rows and fields. Existing reports and historical snapshots are preserved.

The parsed review is held in a separate in-memory review session across route unmount/remount. It is not an approved import and must not enter the deferred-import recovery queue merely because its screen closes. Closing requires explicit discard while work remains; beforeunload warns even if the review screen has unmounted. Actual process/browser loss can still lose this temporary review, so retain the original source file. Only one file parse and review can run from Home at once.

This does not change the configured import provider. Legacy Import data may already contact a service before returning its result. Only a complete local result with local storage status enters this new review. Already-uploaded/remote and partial results use their previous route; no server file is deleted or deduplicated. A parse completing after Home has already unmounted keeps the established deferred-import behavior and is outside the interactive duplicate-review gate. Legacy Home CSV imports are unchanged. Local CSV worker imports retain their existing no-upload and duplicate-review path.

Goal 4 remains partial: this extends duplicate avoidance, not browser capacity guarantees, historical dataset-pool deduplication, deletion, transactional migration or native acceptance. No cloud/production writes, credentials or permissions are changed by this batch's verification.
