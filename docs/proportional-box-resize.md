# Proportional box-size control

The existing Position/chart/object LayoutFields now includes a collapsed **Resize box proportionally** tool. Choose a listed10-400% preset,review the proposed width/height,and explicitly apply. Both dimensions change through one existing layout command and one Undo step.100% does not create a command. Position,z-order,content,fonts,chart styling,queries and datasets stay unchanged. This scales a stored box,not text or plotted marks;clipping and off-page layouts remain possible and are called out. Fit box within page remains separate.

A percentage binds to the width/height when explicitly chosen. External size changes,Undo or another resize make that choice stale;reset or explicitly choose again before applying. Position-only changes do not invalidate the choice because no coordinates are written. The selector's ref handles select+apply and repeated apply in the same event batch without duplicate scaling. Successful application resets to100%. A thrown callback reports uncertainty and does not retry automatically.

Locked items and unfinished numeric entries refuse actions. Pointer activation of blocked controls prevents an accidental blur-commit of the old numeric field. The scale selector remains focusable with aria-disabled and ignores edits while blocked. Collapsing the disclosure restores an owned descendant focus to its summary;outside focus/blur are not stolen. Choices are temporary tool parameters,not saved report content;selection replacement resets them through the existing keyed inspector. No extra global shortcuts are added.

Chart source and target boxes must meet the existing rendered320x220 minimum. Correct an invalid legacy source manually first. Element boxes use existing zero minima but must have positive finite stored/target dimensions. Unsupported percentages,invalid geometry,unsafe target sizes and underflow-to-zero refuse without partial writes. Arithmetic uses ordinary binary64 geometry without integer rounding;this is not pixel-perfect typography or responsive layout.
