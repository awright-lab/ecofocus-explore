# Bring a selected box inside the page

The existing Position, chart-options and object-options coordinate panels now include **Fit box within page**. The panel shows the proposed X/Y and dimensions before the user applies one change through the existing layout command. It uses the builder's actual 1280 × 760 page constants, independently of zoom and grid snapping.

The operation clamps an off-page box to the page bounds. If a box is larger than the page, it first shrinks proportionally until both dimensions fit, then adjusts position. It never enlarges smaller boxes, changes their layer, rearranges other objects, or alters text, fonts, styling, analysis results, data or historical snapshots. It fits the bounding box only: existing text and chart content may still clip or become crowded. The panel says so explicitly and recommends reviewing before export. This is not automatic responsive layout or export preflight certification.

Already-contained boxes produce no command or redundant history entry. Unsupported, nonpositive, nonfinite, excessive or underflowing geometry refuses instead of creating a malformed box. There is no automatic clamping outside this explicit action, and existing negative coordinate authoring remains available.

Chart frames enforce a minimum 320 × 220 size. The fit model and renderer now share those constants. A proportional fit that would fall below either minimum is explicitly refused, including a currently undersized chart; it never reports such a chart as already contained. The user must change its dimensions manually. The Position, chart-options and object-options panels pass the actual item kind: ordinary canvas elements have no chart-frame minimum and can still fit smaller boxes. This does not change the renderer's existing limits or silently enlarge legacy chart boxes.

The control honors the selected item's rendered lock state and shares unfinished numeric-field protection with the movement buttons. Blocked pointer/mouse activation keeps an unfinished entry intact. If a valid numeric entry commits on blur in the same batch as a fit click, that stale click is ignored; a subsequent activation uses the current geometry. The button remains mounted when the fitted box no longer needs a change, retaining focus. Proposed/no-change/blocked feedback is exposed as a status, while command exceptions report that the change could not be confirmed rather than claiming an applied change was undone. Existing save/recovery acknowledgement remains authoritative.

## Verification and boundaries

Model tests cover representative shapes, positions, aspect-ratio preservation, no enlargement, idempotence, input immutability, supported numeric bounds and 500 deterministic element boxes. Chart tests cover minimum boundaries, extreme tall/wide proportions and undersized legacy boxes. Integrated component checks cover proposal-only rendering, no-op writes, focus continuity, locks, unfinished fields, current prop replacement, both options-panel routes and unapplied/applied callback exceptions. An actual App journey uses a synthetic 1,000-row/30-field study with an oversized chart, off-page text and a historical snapshot, exercising Undo/Redo, existing Lock, staged blur, shortcut ownership, simulated denied save, Retry and same-process reopen with complete expected draft/source comparisons. A separate App regression first confirms the actual frame's 320 × 220 CSS minimum, then checks refusal without writing for unsafe tall/wide/currently undersized charts, retains Undo and allows the smaller element box. Simulated DOM confirms the frame properties, not native pixel geometry.

Native keyboard default activation, screen reader/touch, actual visuals, browser matrix, real quota/crash/multi-tab and asynchronous external command behavior remain unverified. Moving/fitting does not certify universal keyboard safety or content readability. Multi-selection clears individual selection; this action is single-item only. Original goals 16 and 33 remain partial. Production build remains unverified after the earlier EPERM and is not retried. No publication, merge or deployment is included.
