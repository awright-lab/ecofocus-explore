# Imported average cell availability

Imported average results distinguish a real zero from an empty estimate using the existing verified cell-base contract. An imported average with `metadataRefs.source.measureBaseScope === "cell"` and a cell base of zero has no valid numeric observations. Its estimate is unavailable. A value of zero with a positive valid-observation base remains an ordinary numeric zero. Counts and sums retain their existing behavior.

`shared/analytics/resultCells.ts` is the common interpretation boundary. `analyticalCell` returns a status and nullable analytical value. Unverified historical average bases require a rerun; invalid numeric cells are not usable. Transport/stored numeric fields remain unchanged for document compatibility. Raw recovery downloads and portable workspace backups preserve the source representation. Do not interpret a stored placeholder value without its base and source metadata.

Canvas tables, analysis previews, Inspector lead values and report thumbnails label unavailable means. Chart adapters supply null gaps and suppress value labels at missing points. A chart with no verified numeric observations shows an explicit empty state. The local average engine retains observed grouping categories even if all their numeric values are invalid, and includes a warning explaining unavailable estimates. Explicit overall summaries continue to reject an empty valid sample.

Derived lead/top/bottom ranking excludes unavailable cells. Differences and averages require available operands; an explicitly selected unavailable row or missing column is not silently replaced. The original stored measurements remain intact. Historical means without verified cell bases cannot establish available operands until rerun.

XLSX writes unavailable means as text alongside their numeric zero valid-observation base; a real observed zero remains a numeric Excel cell. Legacy unverified numeric bases are rejected by the existing rerun guard. SVG/PDF omit missing bars and point markers, split line paths at missing categories, and show an explicit all-unavailable message. Native PowerPoint charts retain category counts/indexes but omit unavailable numeric cache points and their labels. All-unavailable charts use the raster fallback so the empty-state explanation remains visible. PowerPoint visual acceptance is separate from XML/cache verification.

Analytical JSON packages add `result.cellStatuses`, keyed by row and column. Each cell contains its status and nullable analytical value. The original transport table is retained. Consumers must use these analytical values/statuses rather than treating transport placeholders as estimates. This bounded contract does not add general nullable transport values, imputation, survey variance or statistical inference.
