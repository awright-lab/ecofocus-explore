# Report navigator and object search

Pages → **Browse report** opens a visual page overview and a complete object browser. The overview shows page numbers, titles, current-page context, analysis/object counts and existing cached `DocumentPreview` thumbnails. Page-title/number search is separate from object search. Opening a page or object uses the existing selection callbacks and cue; it never edits, unhides, unlocks, reruns or refreshes content.

## Complete results, bounded rendering

The overview and Pages outline each mount at most **12 page previews**. At most 24 previews therefore exist while the overview is open; switching to objects removes the overview previews. Collapsed outline pages do not construct object lists. Expanded outline lists and the object browser each show at most **25 objects per page**. An outline can have multiple expanded pages, but only its current 12-page batch is mounted. There is no observer timing dependency or ever-growing preview cache.

The existing quick search keeps its first-20-results contract and full count. **Browse all matching objects** opens the complete browser with that query. First, Previous, Next and Last controls expose every result; counts state the visible range and complete eligible count. Page, analysis/chart/table/text/shape/image, visibility and lock filters combine with the query. A removed page filter remains explicit and yields no matches until changed. Query/filter/mode changes start at the first result window; report shrinkage clamps the window.

Page and object pagination only change local navigation state. Existing rename/delete/move, active-page mutation guards, multi-selection and Undo/Redo callbacks are retained. Move/delete/rename focus recovery can cross outline page batches. Selecting a quick result or navigator result brings its page into the outline's batch when it matches the outline filter.

## Search boundary and activation

Object search reads analysis titles/names, recorded human-readable imported source labels, element names and authored text. It never visits respondent rows, analytical cells, image payloads, evidence JSON or hidden technical metadata. Previews independently render their existing cached content; a visual thumbnail is not part of the search index. Authored text is limited to **2,097,152 UTF-16 code units across the whole report**, including when filtering to one page. Over-budget reports explicitly get complete names-only results and no text excerpts. Queries retain the **200 input-code-unit** budget. Lookup is literal and case-insensitive, not semantic research discovery. Unicode case-fold expansion is not used to fabricate an incorrectly positioned excerpt; browser listings can instead show a bounded authored-text prefix.

Each search computes the full eligible count but retains only the requested window (maximum model window: 100). There is no persistent index keyed only by mutable array identity. Same-reference report updates are seen on the next render and activation. Result records capture the page/object identifiers at creation, so even in-place identifier changes cannot redirect an obsolete button. Activation checks a JSON tuple of page ID, object kind and object ID against current data, rejects missing/ambiguous identities, and rechecks the current query and filters independently of the first-20 cap. IDs are opaque, including Unicode and punctuation; no DOM selectors are constructed from them. Duplicate names have distinct ordinal/page context. Reordering can change an ordinal but cannot redirect selection to another ID.

The dialog traps focus, makes the background inert, owns canvas shortcut keys, closes on Escape outside IME composition and restores its opener. Focused results removed on rerender return focus to search only if focus was still owned; deliberate outside focus is respected. Text excerpts have associated accessible descriptions. Failed previews have a page-local fallback; opening the page remains available. Stale activation and missing filtered-page states explain why no navigation occurred.

## Evidence and limits

Model, component and actual-App regressions cover 100 pages / 2,000 authored objects plus a synthetic analytical table, all-match enumeration, match 21 and the last match, Unicode IDs, duplicate names, filters, names-only fallback, stale/ambiguous activation, same-reference updates, focus, bounded mounting and preview failure. Existing authoring regressions exercise genuine document commands, saving, Undo/Redo and reopen without replacing those implementations.

The [browser validation record](validation/report-navigator/README.md) includes a reproducible local-only runner, measured observations, desktop/narrow/200% native Chromium zoom screenshots and explicit gaps. Chromium keyboard, focus, scrolling and accessibility-tree checks were actually run; actual screen-reader, touch and other-browser acceptance remain unverified. This improves the navigator's acceptance evidence and does not certify the entire builder, chart canvas or original goal 16.
