# Start a comparison review from current source fields

The optional report-analysis shortcut in Group comparisons suggests the current outcome and breakout field roles from an existing imported-field response analysis. It displays the current study, field labels and physical column names. Manual study and field selection remains available.

It starts only an empty review. Research question, unique respondent ID, reference and event codes, exclusions, comparison family, sampling design and research note require explicit choices. The sampling attestation remains unset. No statistical test, network call, report edit or save is initiated by the suggestion. Applying fields opens the existing comparison editor's source binding and code-choice scans. The comparison engine counts and tests the actual source rows only after the user supplies and reviews the required choices.

Suggestions support original complete local imports with 1–50,000 rows and a recorded analysis of at most 5,000 cells. Numeric means, authored/derived outputs, overall synthetic grouping, weighted, filtered, audience-scoped, wave, managed and remote analyses are refused rather than losing their population or assumptions. Explicit source references at six tile/query/result sites must agree with the local study. Pending settings, missing/ambiguous fields and changed import events refuse the shortcut.

The field-identification helper reads metadata, recorded query context and array lengths without scanning respondent values. Applying the fields invokes existing editor scans; this is not a claim that the whole editor avoids reading rows. They are current field-role suggestions, **not** replayed numerical evidence or proof that a historical field ID always denoted the same physical column. The visible column names and subsequent explicit comparison review are required. A private in-memory receipt rechecks the recorded tile and current study metadata when Apply is activated. A changed field, analysis or import refuses application. Raw-row edits do not invalidate a field-only hint; the later comparison engine independently seals and validates those rows.

Existing working plans, including alpha-only edits, are retained. The parent editor checks pending edits synchronously so a typed edit followed by Apply in the same React batch cannot be replaced. Suggestions are not persisted or automatically updated into a plan. The action remains focusable with an explanatory refusal when unavailable; long reports have a searchable first-100 list that retains the selected analysis.

Regression coverage includes actual imported-query fixtures, all six conflicting-reference sites, missing/stale/unsupported context, descriptor-based refusal before query/metadata getters, no respondent-value reads, receipt tampering/currentness, real parent edit races, and an explicitly reviewed synthetic workflow with independent respondent counts and Holm-adjusted probabilities. This does not establish native browser or assistive-technology behavior, live Snowflake correctness, production build readiness, crash durability, or general arbitrary-JavaScript sandboxing. Goal 26 remains partial; this is an optional workflow improvement, not full insight-feed completion.
