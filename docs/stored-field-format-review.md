# Selected-field stored-format review

The Stored rows inspector offers an explicit **Review field value formats** action for the selected exact stored key. A completed review partitions every row in the complete frozen snapshot into four disjoint groups: parsed finite numbers, nonblank values rejected by the shared imported-data numeric parser, blank/whitespace strings, and missing own properties. The total must reconcile to the snapshot row count. Empty strings are counted separately within the blank group.

Each group has an **Inspect rows** action that applies its explicit display-search mode and exposes original source row positions and reversible stored values. The review covers all snapshot rows even when another row search or field-page filter is active. Text and case settings do not constrain format groups. It does not change the study, preparation history, report, analysis filters, published snapshots or saved storage.

Reviews run in 250-row chunks with progress, cancellation and the existing 30-second scheduled deadline. No partial totals are presented. A synchronous operation owner prevents duplicate starts before React rerenders. Field changes, source snapshot refresh/replacement, capture unavailability and unmount abort and invalidate pending work. Late replies cannot replace current totals. Switching away and back requires a fresh review. The Cancel and category controls remain mounted with guarded aria-disabled states, avoiding focus loss when completion or invalidation makes them unavailable; no automatic focus transfer occurs.

Formatting is not analytical eligibility. Numeric-looking missing codes such as 999 remain numeric. Dollar/percent notation follows the existing parser without conversion; percent text retains its written magnitude. Missing properties differ from blank strings. The inspector uses exact keys, whereas analytical lookup may accept case aliases. It does not infer field meaning, weights, study-specific missing codes or statistical validity. Snapshot capture limits and its synchronous final verification remain unchanged; native event-loop deadlines, responsiveness, memory, visual layout and assistive technology acceptance are unverified.

Verification includes independently specified row partitions, equality with all four existing display searches, own prototype-like keys, empty studies, invalid/forged inputs, cancellation and 50,000-row counts. Component tests cover all inspection actions, context invalidation including returning to a previous field, late replies, duplicate starts, failure/retry and focus ownership. The actual App synthetic 1,000-row/30-field workflow reviews 400 numeric/400 rejected/200 blank/0 missing values despite a preceding single-row search, inspects the numeric group, protects canvas Delete/Backspace and compares complete saved study/report/history and raw bytes through same-process reopen. There is no real respondent data, live request, native browser or actual crash/quota validation. A pre-fix regression reproduced old totals reappearing on return to a prior field; the revision clears context outcomes. The base 82-file publication proposal and all backups remain unchanged. No new original goal is declared complete; independent review of this candidate is pending.
